Developer experience

Build the perfect
computation.

Our SDK lets anyone submit a privacy-preserving computation in 5 lines of Python. The cryptography runs invisibly underneath.

Read the docs ↗
from mpc_sdk import MpcClient, Operation

# 5 lines to run MPC
client = MpcClient(party_id=1, n_parties=3)
client.connect(["node2:8002", "node3:8003"])
result = client.compute(
  Operation.AVERAGE,
  my_input=85_000
)

✅ Result: 85,000 OMR/year
Proof valid: True
