# MPC Network

A decentralized secure multi-party computation network built with Rust, Solidity, and ZK-STARKs.

## Structure
- `crypto/` — cryptographic engine (SPDZ, secret sharing, ORAM)
- `node/` — P2P network layer
- `contracts/` — Solidity smart contracts
- `zkproof/` — ZK-STARK proof generation
- `sdk/` — Python SDK
- `dashboard/` — Professional UI
